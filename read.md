# Even and Odd Number Checker

## Project Description

This project is a simple Python program that accepts a number from the user and determines whether the number is even or odd.

## Objective

The objective of this project is to practice conditional statements and the modulus (`%`) operator in Python.

## Technologies Used

- Python IDLE / Python Interpreter

## How It Works

1. The program asks the user to enter a number.
2. The `%` operator is used to find the remainder when the number is divided by 2.
3. If the remainder is 0, the number is even.
4. Otherwise, the number is odd.
5. The program also correctly handles negative numbers.

## Program Logic

If number % 2 == 0
    Number is even
Otherwise
    Number is odd
